AUTO-SKIP v0.3 - BUILD

1. Open Auto-Skip.sln in Visual Studio.
2. Select Release and x64.
3. Build -> Build Solution (Ctrl+Shift+B).

Output:
    bin\Release\AutoSkip.asi

Requirements:
    Visual Studio 2022 or newer
    Desktop development with C++
    MSVC v143 toolset
    Windows 10/11 SDK

AutoSkip.ini is not automatically copied into bin\Release.
Use the included AutoSkip.ini next to AutoSkip.asi when installing.
